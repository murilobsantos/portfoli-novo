# Política do devlog

O devlog é parte do portfólio, não uma página decorativa. Adicione uma entrada
sempre que houver uma entrega relevante: funcionalidade publicada, correção
importante, mudança de arquitetura, deploy ou aprendizado técnico verificável.

## Checklist de uma entrada

- Nova entrada em `src/data/devlog.ts`.
- Título que descreva a entrega, não apenas a intenção.
- Contexto, mudanças realizadas e próximo passo concreto.
- Link para demo, issue ou repositório quando existir.

O relógio exibido na página mostra o horário local em tempo real; ele não
substitui a data editorial da entrada, que deve ser atualizada junto do código.

As atualizações antigas foram condensadas em uma linha do tempo de marcos para
preservar a narrativa sem manter blocos repetitivos de texto.
