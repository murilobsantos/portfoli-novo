# Portfólio de Murilo Santos

Vitrine pessoal de Murilo Santos, desenvolvedor criativo que une front-end,
produto, direção de arte e mundos interativos. A identidade atual usa o
**jianghu** como metáfora para uma jornada de criação: cada projeto é um
território com contexto, limites e evidências próprias.

[Visitar o portfólio publicado](https://portifoliomurilo.vercel.app)

## O que está no portfólio atual

- **Echoes of Divinity** — vertical slice autoral em Godot, com combate,
  exploração, atmosfera e validação técnica.
- **Landing Pages** — coleção de cinco experiências responsivas para setores
  diferentes, com direção de arte e front-end próprios.
- **Universo de Histórias** — plataforma narrativa com cadastro, autoria,
  publicação e leitura pública persistente.
- **Project Argus** — estudo técnico de investigação de segurança autorizada,
  com governança, evidências persistentes e controles humanos explícitos.
- **Kawaii Reverie** — microexperiência interativa concluída.

## Tecnologias

`Next.js` · `React` · `TypeScript` · `Tailwind CSS` · `Godot`

## Executar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

Para validar a versão de produção localmente:

```bash
npm run lint
npm run build
```

## Estado e evidências

O site publicado é a referência para o estado visual atual. Cada case informa
se representa produto funcional, vertical slice, estudo técnico ou conceito
encerrado; o portfólio não apresenta protótipos como produtos concluídos.

Uma captura da interface wuxia anterior foi mantida apenas como histórico em
`docs/screenshots/portfolio-wuxia-historico-2026-08-13.png`. Ela não descreve
a versão atual e não deve ser reutilizada como imagem de apresentação.
